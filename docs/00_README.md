# 00 — README: пакет ТЗ «Анонимный Дед Мороз: Путь к Тысяче Вершин»

> Версия 1.0 · 2026-11-03 · Рабочее название игры: **«Анонимный Дед Мороз: Путь к Тысяче Вершин»** (меняется в `config.ts`).
> Это входной документ. ИИ-агент (Cursor) **обязан прочитать все четыре файла целиком** перед первой правкой кода.

---

## 1. Что строим

Браузерная 3D-игра-квест на **three.js** для **одного получателя** (участник тайного санты по MTG). Дед Мороз идёт из Сибири через 8 локаций (вдохновение — классический роман «Путешествие на Запад») к горам, где делает фотографию. Каждая локация связана с **физическим мини-подарком** в посылке. Главный подарок — карта **Wooded Foothills (Zendikar Expeditions, рус.)** — «и есть та самая фотография».

Игра **не заменяет** подарок: если сайт не открылся, посылка должна оставаться полноценной (см. «режим парашюта» в `01_TECH_SPEC.md` §11.5).

## 3. Порядок чтения и приоритет при конфликтах

1. `00_README.md` → `03_GIFTS.md` → `02_STORY.md` → `01_TECH_SPEC.md`.
2. **Приоритет истины:** `03_GIFTS` (что реально лежит в коробке) **>** `02_STORY` **>** `01_TECH_SPEC`. Физика важнее сюжета, сюжет важнее реализации.
3. Если агент находит противоречие — **не выбирает сам**: записывает в `docs/CONFLICTS.md` (дата, файлы, цитаты, предложение) и продолжает с вариантом из более приоритетного документа.
4. **Протокол изменений:** любое изменение ID, названия подарка, порядка глав или ключевых предметов делается сразу во всех затронутых файлах; затем запускается `npm run check:content` (см. `01_TECH_SPEC.md` §18). Коммит с несогласованными документами запрещён.

## 5. Жёсткие ограничения (нарушение = дефект блокирующего уровня)

1. **Анонимность отправителя.** В коде, текстах, метаданных, названиях файлов, git-истории деплоя, EXIF/GLB-метаданных нет имён, никнеймов, городов, ссылок на другие проекты автора. Место старта — только «Сибирь». Подробно — `01_TECH_SPEC.md` §16.
2. **Не упоминать реальное местонахождение получателя.** Финальная локация подаётся как сказочные «горы Поднебесной / Лесистые предгорья», без фраз вида «ты сейчас в…», без реальных названий городов получателя. Никаких предположений о личной жизни получателя.
3. **Ноль внешних запросов:** шрифты, библиотеки, аудио, изображения, карты — всё хостится на своём сервере. Никакой аналитики и трекеров.
4. **Авторские права:** не использовать арт, логотипы, символы маны и тексты карт Wizards of the Coast; никакого официального арта Wooded Foothills в игре (решение по умолчанию, вопрос Q10). Сторонние 3D/аудио — только CC0/CC-BY, с записью в `public/CREDITS.md`. Персонажи «Путешествия на Запад» (XVI век) — общественное достояние, но **визуальные дизайны оригинальные**, без копирования современных игр и экранизаций.
5. **Не ломать подарок:** игра не должна блокировать получение посылки; все «замки» по конвертам мягкие (`soft`).
6. **Без насилия и «game over»:** провал любого испытания = мягкий возврат на чекпоинт с шуткой.

## 8. Как запускать работу в Cursor

1. Положить эти файлы в `docs/` репозитория прототипа (**не** в `public/`).
2. Добавить правило `.cursor/rules/adm.mdc` (шаблон — `01_TECH_SPEC.md`, Приложение A).
3. Давать агенту **по одной задаче** из `01_TECH_SPEC.md` §19 (шаблон промпта — Приложение B), с требованием в конце: `npm run check:content && npx tsc --noEmit && npm run build`.
4. После каждой фазы — коммит с тегом `phase-N` и ручная проверка автором по чек-листу приёмки (Приложение C).
