## 1. Логлайн, тон, гайд стиля

**Логлайн.** Анонимный Дед Мороз получает секретное задание: доставить внучку не вещь, а впечатление — вид, который стоит увидеть. Через тайгу, горы, Байкал, степь, огонь и пещеру он идёт с компанией героев «Путешествия на Запад» к туманным лесистым горам, где делает фото. Фото и есть главный подарок.

**Тон:** тёплый, смешной, без сарказма над получателем. Дед Мороз — усталый волшебник-бюрократ с добрым сердцем. Юмор — ситуативный и словесный; MTG-отсылки лёгкие, читаются без знания правил.

**Гайд стиля (обязателен для всех текстов, включая тексты агента):**
1. Предложения короткие. Реплика ≤ 220 символов. Не более 3 строк на экране.
2. Обращение к получателю — только токен `{{kid}}` (по умолчанию «внучок»), только в именительном/звательном падеже.
3. Запрещено: упоминать города/страны получателя и отправителя, фразы «ты сейчас в…», реальные имена, ники, политику, брань, насилие. Отправная точка — только «Сибирь». Конечная точка — «горы Поднебесной», «Лесистые предгорья».
4. Никаких прямых цитат из карт, правил и flavor text MTG. Допустимы названия механик и карт как узнаваемые шутки (Mana Leak, Black Lotus и т. п.), короткие и самодельные.
5. Провал/ошибка игрока = смешная реплика, не упрёк.
6. Дед Мороз всегда подписывается «Анонимный Дед Мороз».

## 4. Сквозные арки

1. **Операция «Экспедиция».** Кодовое имя задания (намёк на Zendikar Expeditions). Письмо и финал рифмуются.
2. **Камера «Зенит».** Корпус даёт CH00; линзу — CH03; плёнку — CH05; ремешок — CH06; штатив — CH07. Сборка на верстаке в CH08 → `KEY_CAMERA`.
3. **Грамота и печати.** `KEY_PASSPORT` (CH01) хранит 8 печатей S01…S08; журнал (J) показывает их. Это **цифровое** отражение физической грамоты G01.
4. **Счётчик «81 испытания».** Сунь регулярно напоминает, сколько испытаний «осталось»; Дед Мороз торгуется до восьми. Каждая завершённая глава снижает счётчик (81 → 80 → … ) — шуточный HUD-элемент в журнале.
5. **Пять цветов маны ↔ пять печатей/стихий.** CH01: печати W/U/B/R/G оформлены как «стихии» (шутливое соответствие, не догма).
6. **Fetch-финал.** В CH08 «Тропа» работает как fetchland: Дед Мороз платит 1 «вздох» (шуточная «жизнь»), «жертвует» тропу и находит **Лес и Гору**: это две видовые точки фото.

## 5. Главы

Для каждой главы: сводка → визуал → цели → ритм → мини-игра → NPC/интерактивы → диалоги → заметки для подарка → пасхалки → звук → выход. Цели имеют ID `CHxx.Oyy` и задаются в `ChapterDef` (см. `01_TECH_SPEC.md` §8).

### CH00 — Мастерская (`ZONE_WORKSHOP`)

**Сводка.** Дом и двор Деда Мороза в Сибири. Приходит письмо. Игрок осваивает управление и забирает камеру.
**Визуал.** Тёплые окна, снег, закат, дым из трубы; фон — тёмный ельник. Туман слабый. Частицы: `snow_light`.
**Размер зоны:** 140×140 м, одна лёгкая высотная складка.

**Цели**
- CH00.O01 Прочитать письмо на столе
- CH00.O02 Найти камеру в чулане
- CH00.O03 Взять варежки и посох у двери (посох уже в слоте 1)

### CH01 — Тайга (`ZONE_TAIGA`)

**Сводка.** Дед Мороз идёт сквозь тайгу, находит Гору Пяти Печатей, под которой заточён Сунь Укун. Нужно сорвать пять печатей (W/U/B/R/G).
**Визуал.** Густой ельник, зелёно-синий туман, лучи света, клочки снега. Частицы: `snow_light`, `fireflies_day` (споры). Размер: 320×320 м, холмы до 25 м.
**Размер зоны и разметка:** центр — Гора Печатей; пять полян (по одной печати) по кругу радиусом 90–130 м.

**Цели**
- CH01.O01 Добраться до Горы Пяти Печатей
- CH01.O02 Сорвать пять печатей (0/5)
- CH01.O03 Освободить Суня
- CH01.O04 Взять грамоту и выйти на тракт

**Ритм:** Леший сбивает с пути (комедия) → 5 полян с мини-загадками → освобождение → подарок.
**Поляны (печати):**
| Печать | Предмет | Загадка | Тип |
|---|---|---|---|
| W (белая) | `KEY_SEAL_W` | «светлая» поляна; нужно «растопить» лёд на камне посохом | F + посох |
| U (синяя) | `KEY_SEAL_U` | пруд; подойти по камням (простое равновесие по высоте) | движение |
| B (чёрная) | `KEY_SEAL_B` | тёмный бурелом; идти на звук | навигация |
| R (красная) | `KEY_SEAL_R` | костровище; зажечь очаг (E три раза по кругу) | интерактив |
| G (зелёная) | `KEY_SEAL_G` | лесная тропа; найти дупло (подсказка Лешего) | диалог+поиск |

**Интерактивы:** 5 печатей, `NPC_LESHY`, `OBJ_FIVE_SEALS_ROCK`, `OBJ_TRAIL_SIGN`×6, `OBJ_CHECKPOINT_T1..T3`.

### CH02 — Перевал (`ZONE_PASS`)

**Сводка.** Высокий горный перевал с крутыми склонами. Харчевня «Пельмень», где Бацзе голоден. Собрать ингредиенты и сварить пельмени.
**Визуал.** Красно-серые скалы, серый туман, ветер. Частицы: `snow_heavy`. Размер: 360×300 м, перепад до 60 м; тропа с серпантином.
**Механики:** подъём (угол до 40°); «облако» Суня на 3 разрывах (`cloud_spot`); `MG_PELMENI`.

**Цели**
- CH02.O01 Дойти до харчевни «Пельмень»
- CH02.O02 Собрать ингредиенты (0/4: мука, мясо, лук, пряность)
- CH02.O03 Сварить пельмени (`MG_PELMENI`)
- CH02.O04 Взять Бацзе в компанию

**Где ингредиенты:** мука — заброшенная мельница (ниже по склону); мясо — охотничья заимка (за расщелиной, нужно облако Суня); лук — огород у харчевни; пряность — лавровый куст на утёсе.
**`MG_PELMENI`:** 3 раунда «лепки»: шкала в ритме, нажать E в зелёной зоне. Допустимо 5 попыток; ошибка = «пельмень слепился в оладушек» (смех), без штрафа.

**Механики:** подъём по тропам; верстак сборки камеры; «Тропа-fetch»; `MG_PHOTO` — съёмка в видоискателе.

**Цели**
- CH08.O01 Встретить Старца Гор
- CH08.O02 Собрать камеру на верстаке (линза, плёнка, ремешок, штатив, корпус)
- CH08.O03 Поднять взгляд: найти «Тропу-fetch»
- CH08.O04 Сделать кадры на точке Лес и точке Гора (`MG_PHOTO`)
- CH08.O05 Выбрать лучший снимок и «проявить» фото

## 11. Флаги, события и триггеры, которые задаёт конфиг зон (не DLG)

Эти идентификаторы используются в диалогах выше, но «производятся» интерактивами, триггер-зонами и мини-играми в `src/content/zones/<zoneId>.json`. Агент **обязан** реализовать каждый пункт; `check:content` проверяет, что у каждого `event:` и `flag:`, на который ссылается DLG, есть производитель.

| Идентификатор | Тип | Производитель | Условие |
|---|---|---|---|
| `ch00_icicle_melted` | flag | `OBJ_ICICLE_GATE` (`useItem: ITM_STAFF`, F) | посох выбран, игрок рядом |
| `TRG_TAIGA_EXIT` | trigger | зона на выходе тайги | вход при `ch01_passport_given` → `!obj CH01.O04 done` + `chapter complete` |
| `KEY_SEAL_W/U/B/R/G` | pickup | `OBJ_SEAL_W/U/B/R/G` | см. таблицу полян CH01; при каждом подборе обновляется счётчик O02 (0/5) |
| `CH03: MG_THIN_ICE_DONE` | event | `MG_THIN_ICE` | игрок дошёл до `OBJ_PALACE_DOOR` → `!obj CH03.O03 done` |
| `ITM_ICE_SHARD` | pickup (стак ≤ 3) | 3 объекта `OBJ_ICE_SHARD_01..03` | обновляет счётчик O02 (0/3) |
| `ITM_TEA_CHEST` | pickup (стак ≤ 3) | 3 объекта `OBJ_TEA_CHEST_01..03` (подсказка Бацзе доступна) | обновляет счётчик O02 (0/3) |
| `MG_SAND_BRIDGE_DONE` | event | `MG_SAND_BRIDGE` | порядок камней «ветер, песок, вода, небо» |
| `CH05_LAVA_BRIDGES_DONE` | event | 3 интерактива `OBJ_LAVA_BRIDGE_01..03` (F + посох на лаву, 12 с заморозки) | все три мостика проложены |
| `MG_FIRE_FAN_DONE` | event | `MG_FIRE_FAN` | успех |
| `ITM_LANTERN_OIL` | pickup | `OBJ_OIL_JAR` | подбор → `!obj CH06.O02 done`, `!obj CH06.O03 activate` |
| `MG_LANTERNS_DONE` | event | `MG_LANTERNS` | порядок «короткий-длинный-длинный-короткий» |
| `ITM_KITE` | pickup | `OBJ_KITE_TREE` (подсказка Бацзе) | подбор |
| `CH07_LANTERN_FIXED` | event | `OBJ_TOWER_LANTERN` (F + посох) | зарегистрирован после `ch07_met_hu` |
| `MG_BARGAIN_DONE` | event | `MG_BARGAIN` | любой исход (результат влияет на шутки, не на прогресс) |
| `MG_PHOTO_DONE` | event | `MG_PHOTO` | принят хотя бы один кадр, набравший ≥ 60 очков (§12 `01_TECH_SPEC.md`) |
| `PHOTO_DEVELOPED` | event | UI «Проявка» | анимация проявки завершена |

**Расходуемые предметы:** `!take <ITM> [N]` без N снимает 1. Условие `item:ITM>=N` означает «не менее N в инвентаре».
